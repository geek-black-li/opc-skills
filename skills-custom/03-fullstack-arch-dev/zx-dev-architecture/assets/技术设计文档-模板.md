### 0.1 给 Codex 的使用规则

1. PRD 定义“做什么和如何验收”，本文档定义“如何实现”。业务行为、规则、数据对象和用户文案只引用 F、BR、AC、NFR、PERM、DATA ID，不在这里复制正文。
2. 当前代码、配置、迁移、测试和 lockfile 是现状证据；本文档的“目标设计”不能被误当成已经实现。
3. 用户最新明确指令可以改变设计。若与已批准 ADR 或公共契约冲突，先说明影响；确认后更新本文档、任务和失效标记。
4. 技术选择必须基于约束和证据。框架、分层、数据库、认证、删除策略、迁移回滚方式均是条件性决策，不是模板默认值。
5. 依赖精确解析版本以 lockfile 和运行时版本文件为准；声明文件中的版本范围只代表允许范围。
6. 只有会改变产品行为、数据、安全、公共契约或需要新增权限的问题才阻塞实施；低风险可逆问题可记录最小假设后继续。
7. handoff_status=ready 只表示技术设计可以进入实施计划，不代表已授权修改代码、提交或发布。
